# M2M Schemas

This directory contains structured schemas for AI-assisted strategic frameworks.

## Available Schemas

### Executive Board Architecture

**Location:** `executive-board/`

The VN-1 Nexus Strategist framework — a meta-leadership avatar built from elite executive archetypes for strategic decision-making, product development, and AI governance.

- `vn1-nexus-strategist.schema.json` — Machine-readable schema
- `README.md` — Usage guide and documentation

## Usage

These schemas are designed to be:

1. **Referenced by AI assistants** for structured decision-making
2. **Loaded programmatically** for automated strategic analysis
3. **Used as prompt templates** for consistent evaluation frameworks

## Adding New Schemas

When adding new schemas:

1. Create a subdirectory with a descriptive name
2. Include both `.schema.json` (machine-readable) and `README.md` (human-readable)
3. Update this index file
4. Follow JSON Schema draft 2020-12 conventions where applicable
